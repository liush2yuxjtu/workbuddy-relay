# 接力包（WorkBuddy 跨电脑接力）

## 这个技能解决什么

用户在 A 电脑上和 WorkBuddy 做了一半的事，要到 B 电脑上继续。以前只能用"微信文件传输助手"来回传文件，对话上下文还会丢。
本技能把 **"交接说明（对话精华）+ 产出文件"** 打成一个接力包，放进国内网盘（坚果云）或同步文件夹；另一台电脑一句话取回，WorkBuddy 读完交接说明就能接着干。

用户是普通上班族，不是程序员。**和用户说话一律用大白话**，不要提 Python、WebDAV、命令行、路径这些词，除非用户问。

## 第 0 步：找到能运行脚本的 Python（每次会话只做一次）

脚本在本技能目录：`scripts/relay.py`（下文记作 `RELAY`，请用绝对路径；技能目录一般是 `~/.workbuddy/skills/workbuddy-relay/`）。

按顺序试，第一个能输出版本号的就用它（下文记作 `PY`）：
1. `python3 --version`
2. `python --version`（Windows 上注意别是微软商店的假 python）
3. WorkBuddy 自带的 Python：在 `~/.workbuddy/binaries/python/versions/` 下面找 `python3` 或 `python.exe`（macOS 一般在 `*/bin/python3`，Windows 在 `*\python.exe`，用文件搜索找到即可）

要求 Python 3.8+。只用标准库，不需要 pip 安装任何东西。

## 第 1 步：检查有没有设置过中转站

运行 `PY RELAY status`。
- 显示 `✅ 中转站正常` → 直接去第 2 步或第 3 步。
- 显示"还没设置中转站" → 按下面引导用户 **只设置一次**（每台电脑各设置一次，填同一个账号）。

### 引导设置（用大白话，一步一步）

先问一句：**"你电脑上有没有正在用的、会自动同步的网盘文件夹？比如坚果云、百度网盘同步空间、OneDrive、iCloud 云盘。"**

**A. 推荐：坚果云（免费、国内速度快、不用装软件）**
告诉用户：
1. 用浏览器打开 jianguoyun.com，用手机号注册/登录（免费版就够用：每月上传 1GB）。
2. 点右上角头像 →「账户信息」→「安全选项」→ 找到「第三方应用管理」→ 点「添加应用密码」，名字随便填（比如 WorkBuddy）→「生成密码」。
3. 把 **登录账号（邮箱或手机号）** 和 **刚生成的应用密码** 发给我。（提醒：是"应用密码"，不是登录密码。）

拿到后运行：
`PY RELAY setup webdav --user "账号" --password "应用密码"`
成功后告诉用户"设置好了"，并提醒：**另一台电脑上也要装这个技能，填同一个账号和应用密码**（应用密码可以在坚果云里再看/再生成一个）。
不要在之后的回复里重复显示密码。

**B. 已经有同步文件夹 / 用 U 盘**
请用户告诉你那个文件夹在哪（或者让用户把文件夹拖进对话框）。运行：
`PY RELAY setup folder --path "那个文件夹"`
提醒用户：两台电脑要用同一个网盘账号；用 U 盘的话，打包后把 U 盘带到另一台电脑，再设置成 U 盘里同一个文件夹。

## 第 2 步：打包（用户要离开这台电脑时）

1. **写交接说明**：在本次工作文件夹里新建 `交接.md`，按下面模板写，要让"另一台电脑上的、完全不记得这次对话的 WorkBuddy"看完就能接着干：

```markdown
# 交接：<一句话主题>
- 打包时间：<日期时间>　来自：<这台电脑>

## 用户想要什么
<用户的原始需求，尽量保留原话；有格式/风格/对象等要求都写上>

## 已经做完的
- ...

## 关键决定和用户的偏好
- <用户确认过的选择、否掉的方案、口味偏好、数据口径>

## 还没做完的 / 下一步
1. <最具体的下一步>
2. ...

## 文件清单
- 文件/xxx.xlsx —— <一句话说明是什么、是不是最终版>

## 重要对话摘录（可选）
> <用户说过的关键原话>
```

2. **选文件**：默认带上本次对话产出或用到的文件（当前工作文件夹里的成果文件 + 用户提到的文件）。临时文件、安装包、缓存不要带。单个文件超过 400MB（比如长视频）不要带，告诉用户用 U 盘单独传。
3. 运行：
`PY RELAY push --title "<简短主题>" --note "<交接.md 的路径>" --files <文件或文件夹1> <文件或文件夹2> ...`
4. 用大白话汇报，例如：
"已经打好接力包啦：交接说明 + 6 个文件。到另一台电脑上打开 WorkBuddy，说一句 **『接着做上次的』** 就行。"

## 第 3 步：取回并接着做（在另一台电脑上）

1. 运行 `PY RELAY list`，看有哪些接力包。
   - 用户没指定 → 用最新的；用户提了主题（比如"那个季度报告"）→ 用标题匹配的那个。
2. 运行 `PY RELAY pull <latest 或 序号 或 主题关键词>`
   - 默认放到 `~/WorkBuddy/接力/<包名>/`；输出里 `NOTE_PATH=` 就是交接说明，脚本会把内容直接打印出来。
3. **完整读一遍交接说明**，然后用 3～5 句话告诉用户："上次做到了…，你当时定了…，下一步我打算…，要我直接开始吗？"
   用户同意（或用户一开始就说了要做什么）就 **在取回的文件夹里** 接着干，产出也放在那里。
4. 做完这一轮，主动问一句："要不要再打个接力包，方便你换电脑继续？"

## 主动提醒

- 用户说"今天先到这""下班了""回家再弄""明天继续"等，主动问：**"要不要打个接力包？到另一台电脑一句话就能接着做。"**
- 新会话一开始用户说"继续/接着弄"但当前对话里没有上下文，先 `PY RELAY list` 看看有没有接力包。

## 出错时怎么跟用户说

| 脚本提示 | 跟用户说 |
|---|---|
| 账号或应用密码不对 | "坚果云账号或应用密码好像不对，注意要用『第三方应用密码』，不是登录密码。重新发我一下？" |
| 网盘拒绝了请求 / 请求太频繁 | "坚果云这会儿有点忙（免费版半小时限 600 次请求，或本月流量用完了），过半小时再试，或者先用 U 盘。" |
| 连不上网盘 | "网络好像连不上坚果云，检查一下网络再试。" |
| 找不到接力包（同步文件夹模式）| "网盘可能还没同步完，等一两分钟再试。" |
| 太大没带上 | "这几个大文件太大没放进去，建议用 U 盘单独拷。" |

## 安全

- 账号和应用密码只保存在本机 `~/.workbuddy-relay/config.json`（仅本人可读），不要写进交接说明、不要打包、不要在回复里显示。
- 交接说明里不要写密码、身份证号、银行卡号等敏感信息。
- 取回时只解压到指定文件夹，不覆盖用户其他文件。
